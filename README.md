# QuantumAI — исходный код сайта

Готовый статический сайт без зависимостей и сборки.

## Запуск

Откройте `dist/index.html` в браузере или запустите локальный сервер из папки проекта:

```bash
python -m http.server 8080 --directory dist
```

После этого сайт будет доступен по адресу `http://localhost:8080`.

## Структура

- `dist/index.html` — разметка всех экранов.
- `dist/styles.css` — стили и адаптивная мобильная вёрстка.
- `dist/app.js` — навигация, настройки, график, банки и локализация.
- `dist/assets/` — логотипы компаний.
- `dist/favicon-qai.png` — favicon и иконка для телефона.
- `.openai/hosting.json` — конфигурация публикации сайта.

Настройки пользователя сохраняются в `localStorage` браузера.
